## Semantic journal retrieval — 2026-11-03

The Assistant now searches synced history by meaning instead of selecting the five newest entries. Added JournalTextEmbedding in JournalCore and made the existing local Qwen embedding actor conform; no native runtime dependency enters Core. SemanticJournalRetriever pages current evidence through the existing on-demand reader, splits long bodies into conservative Unicode-safe passages, compares normalized vectors, and selects the highest-ranked excerpt from each of up to five entries. Existing context budgeting, citation identities and generation flow are reused. JournalQueryPlanner replaces the recent-specific planner name; it passes the question through without date inference. Model discovery uses fixed private/bundled/checkout locations, and embedding resources unload before generation and on failure/cancellation.

This is transient exhaustive semantic search, not a cached vector index. Each preparation recomputes embeddings; only page-local content/vectors and top results are retained. No persistence, keyword extraction, network inference or metadata schema changes were added. No calibrated relevance cutoff or whole-history trend coverage policy is claimed. Passage boundaries can lose cross-boundary meaning. Per-entry/page reads are not an atomic history snapshot; an in-flight native call remains noninterruptible. See EMBEDDINGS.md for details.

Validation: ordinary SwiftPM run discovered 54 tests, with 51 passed, three opt-in tests skipped and zero failures. The separate opt-in native semantic test passed with the actual embedding weights and synthetic Journal fixtures, selecting an older Chinese work-interview entry for an English anxiety question over a newer baking entry. Other new fixtures cover pagination beyond 50, current unsynced body edits, live deletion exclusion, date filters, long-entry excerpt citations, Unicode bounds, invalid vectors and cancellation. Changed Swift files passed strict formatting checks. The macOS app compiled successfully with signing disabled in an isolated temporary products directory; Xcode's signed run product was not overwritten. No real Journal content was read and the new semantic-search UI was not interactively exercised.
